Windows requirements

System Requirements

AnxOS Control Center runs the desktop app and can install the Local Agent on your own Windows PC. Resource needs depend on the server software and templates you choose.

Minimum

  • Windows 10 or Windows 11, 64-bit.
  • 64-bit Intel or AMD processor.
  • 4 GB RAM for the app, Local Agent, and light testing.
  • 2 GB free storage for AnxOS, the Local Agent runtime, logs, and temporary downloads.
  • Internet access for app updates, Marketplace downloads, and dependency installers.
  • Administrator access during Local Agent service installation and some dependency installs.

Recommended

  • 8 GB RAM or more for Minecraft and small game servers; larger modpacks usually need more.
  • SSD storage for faster server startup, backups, and world saves.
  • Stable internet connection for downloads, updates, multiplayer, and remote access providers.
  • Hardware virtualization enabled when using Docker or Docker Desktop.
  • Additional storage reserved for instances, worlds, backups, logs, and imported server packs.

Hosting capacity

  • AnxOS itself does not provide game-server hosting capacity.
  • Your computer supplies the CPU, RAM, storage, and network bandwidth for local servers.
  • Your computer must remain powered on and connected for locally hosted servers to stay online.
  • Busy public servers may need more RAM, faster storage, and stronger upload bandwidth.

Public access

  • Friends can join only when your chosen server and network path are reachable.
  • Public access may require Playit, Tailscale, Cloudflare Tunnel, or router port forwarding.
  • Windows Firewall rules may be required for local servers and managed tunnel providers.
  • AnxOS does not enable remote access by default; provider setup depends on your choices.
