Platform support

System Requirements

AnxOS Control Center runs on Windows 11 x64 and on Debian/Ubuntu x64, and the official Agent package covers headless Linux servers. What your servers actually need depends on the templates you choose.

Windows 11 x64

The desktop app and the built-in Local Agent on your own PC, with Administrator access during the Agent install.

Linux Control Center

Debian / Ubuntu x64

The same desktop app as .deb and .AppImage packages for Debian and Ubuntu desktops.

Headless Agent

Debian 11+ / Ubuntu 22.04+

A systemd service for Debian 11+ and Ubuntu 22.04+ servers, with no desktop required.

Headless Agent

Debian and Ubuntu servers

The official AnxOS Agent package runs without a desktop environment and is managed through its TUI or from Control Center on another computer.

Headless Agent node requirements
Item Details
Operating system Debian 11+ or Ubuntu 22.04+, x64
C library glibc 2.28 or newer
Package Official AnxOS Agent .deb, installed with root or sudo.
Integrity Not code-signed; verify the published SHA-256 checksum.
Service manager systemd; starts with the machine.
Network Loopback (127.0.0.1) by default; network exposure is an explicit opt-in.
Desktop environment Not required.
Memory and storage 4 GB RAM and 2 GB free storage minimum; more for game servers.

Hosting and network

What keeps servers online

AnxOS is the management layer, not a hosting service. These are the constraints to plan around before you invite players.

  • No hosting from AnxOSAnxOS itself does not provide game-server hosting capacity. Your computer, VPS, or server supplies the CPU, RAM, storage, and upload bandwidth.
  • Powered on and connectedYour computer must remain powered on and online for locally hosted servers to stay available; a headless node has the same requirement.
  • A reachable path for playersShareable addresses come from one of: Playit, Tailscale, Cloudflare Tunnel, or router port forwarding. Playit.gg is the integrated provider, Cloudflare Tunnel and Tailscale are configured on the node, and port forwarding is manual at the router.
  • Busy servers need moreFull public servers may need more RAM, faster storage, and stronger upload bandwidth than a small private world.
No hosting, no desktop required

AnxOS does not provide game-server hosting capacity, so plan for the hardware and connection yourself. And a headless Linux server needs no desktop environment: the Agent package runs as a systemd service and is managed through its TUI or from Control Center on another computer.
