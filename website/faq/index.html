Getting started

Before your first server

Do I need a separate Debian or Ubuntu server?

No. Normal users run the Local Agent on their own Windows PC. A remote Debian or Ubuntu machine is one way to keep a node online without your PC, but it is optional and you can add it whenever you want one.

Can I run the AnxOS Agent on a headless Linux server?

Yes. The official AnxOS Agent package runs on Debian 11+ and Ubuntu 22.04+ x64 with no desktop environment. It installs as a systemd service, listens on loopback (127.0.0.1) by default, and shows a one-time pairing code in its TUI. Exposing it to your network is an explicit opt-in.

Why does Windows show a blue SmartScreen warning?

The installer is code-signed, but SmartScreen can still warn when a publisher or a build is new to it. Check that the file came from the official release page and look at the publisher name in the signature before you decide. Do not install a build from anywhere else.

Is macOS supported?

No. macOS is not a supported platform in this release. Do not assume macOS support until it is tested and documented.

Which Linux distributions are supported?

The Control Center desktop app ships for Debian and Ubuntu x64 as .deb and .AppImage packages. Headless Agent nodes are supported on Debian 11+ and Ubuntu 22.04+ x64 with glibc 2.28 or newer. Other distributions are untested for now.

Can I check things from my phone?

There is no phone app in this release. The website covers account pages and desktop app activation; day-to-day server management happens in the desktop Control Center. Public Access providers make a game server reachable to other players, but that is gameplay access, not a management app.

Machines & Agents

Local Agent and remote nodes

Does the Local Agent start with Windows?

It can. The Windows Local Agent is designed to run as a service, so it can start with Windows without leaving the desktop app open.

Can I use a remote server instead?

Yes. Add a Windows desktop or a headless Debian/Ubuntu server with the official AnxOS Agent package and pair it with a one-time code. You can also skip Local Agent setup during remote-only onboarding.

Can I manage both my PC and a remote server?

Yes. AnxOS can show This PC alongside remote servers such as a VPS, NAS, or home server, and each action targets the node you select.

Do I need Node.js?

No. The Agent uses an AnxOS-managed runtime that the app prepares for you, so you do not install a global Node.js version by hand.

Do I need to copy an Agent token?

No. Local pairing is handled automatically on This PC, and normal setup never asks you to copy a token from a config file. A direct Agent URL + token option exists in Advanced Manual Setup for development or recovery only.

How does pairing work — do I need to copy a token?

Adding a computer generates a one-time pairing code on that machine. Paste it once into Pair with Code in the Control Center and the node appears. The code expires, so generate a fresh one if it ages out. No token copying is involved.

What's the .deb Agent package?

It is the official AnxOS Agent package for headless Linux servers. Install it on Debian 11+ or Ubuntu 22.04+ x64 with sudo; it adds the Agent as a systemd service with a CLI and TUI. The package is not code-signed, so verify the published SHA-256 checksum after downloading.

Can I uninstall the Local Agent?

Yes. You can stop the service or uninstall the Agent. Your instances, worlds, and backups stay on disk unless an uninstall option explicitly says it removes them.

Where are my instances stored?

In the instance storage location configured for the node you picked. For This PC, that is a folder on your own computer that you can change, back up, or move yourself.

Hosting

Hosting and hardware

Does AnxOS host the server for me?

No. AnxOS manages servers on hardware you control, and it does not provide hosting capacity by itself. This PC or a remote node supplies the CPU, RAM, storage, and bandwidth.

Does my PC need to stay on?

Yes. A locally hosted server stays online only while your PC is powered on and connected and the instance is running. If that does not work for you, connect a remote node instead.

Can AnxOS install Java, SteamCMD, and other dependencies?

AnxOS can scan for supported dependencies and install some of them through managed flows when the platform and license allow it. Anything it cannot install is reported with instructions instead.

Networking

Letting other people in

How do I let friends join my server?

Use Public Access options such as Playit, Tailscale, Cloudflare Tunnel, or manual port forwarding. Playit.gg is the integrated provider; Cloudflare Tunnel and Tailscale are set up on the node itself; port forwarding is configured on your router. Your provider, firewall, router, and server settings all have to allow the connection.

Accounts

Signing in and local mode

Do I need an AnxOS account?

No. Sign-in is optional. Local mode works offline with Local Owner access, and servers on This PC do not need cloud account features.

What does signing in change?

Signing in adds cloud and remote account features such as account pages, profile settings, and desktop app activation on the website. Local server work keeps working offline without it.
