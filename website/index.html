Add a computer

Adding a computer is the whole setup.

Two paths, one result: a paired node. Desktop or headless, pairing takes a few minutes — manual tokens and JSON are the Advanced recovery path, not the normal one.

Add Computer: desktop and headless paths, the recommended Pair with Code flow, and Advanced Manual Setup for recovery.

Advanced recovery path

Direct Agent URL and token setup is for development, recovery, older Agents, or manual networking. A normal pairing never asks you to copy a token.

Desktop computer Windows or desktop Linux

Installing Control Center on that computer includes the Agent, so AnxOS can prepare it for you.

  1. Install AnxOS Control Center on the computer you are adding.
  2. Open Agent Control in that installation.
  3. Select Connect this computer.
  4. Turn on Another computer will connect to this one.
  5. Select Generate Pairing Code and copy the full code.
  6. Paste the code under Add Computer on the machine you manage from.
Headless server Debian or Ubuntu

Install the official Agent package and pair it from the terminal:

  1. Download AnxOS-Agent-<version>.deb for Debian 11+ / Ubuntu 22.04+ x64.
  2. Install it with sudo apt install ./AnxOS-Agent-<version>.deb.
  3. Run anxos-agent pair and copy the one-time code.
  4. Paste the code under Add Computer in the control center.

Headless Linux

Headless Linux is first-class.

The Agent is the same connection either way — on Debian and Ubuntu it ships as an official package and runs as a system service with a full-screen TUI.

The Agent package

  • Official AnxOS-Agent-<version>.deb for Debian 11+ and Ubuntu 22.04+ on x64.
  • Installs as anxos-agent.service — a systemd unit managed by your package manager.
  • Command line and TUI: run anxos-agent for status, or anxos-agent pair to generate a one-time pairing code.
  • Check for updates with anxos-agent update --check.
  • Linux builds are not code-signed — verify the published SHA-256 checksum for the .deb and the AppImage.
Get the Agent package Setup guide

Control Center itself is also available for Linux x64 as a .deb or AppImage. Use the Agent package when the machine has no desktop.

Security posture

Trust is a feature.

The AnxOS Local Agent securely connects the desktop app to services running on your computer. These are the boundaries it keeps by default.

  • One-time pairing codesPairing codes are one-time and expire; generate a fresh code for each computer.
  • Loopback by defaultThe Agent listens on loopback (127.0.0.1) unless you opt in to network exposure.
  • Signed Windows installerWindows installers are Authenticode-signed.
  • SHA-256 for LinuxLinux packages and the Agent .deb publish SHA-256 checksums; they are not code-signed.
  • Uninstall keeps your dataRemoving the Agent leaves your servers, worlds, and configuration in place.
  • Redacted diagnosticsDiagnostics report fingerprints and timestamps, not secrets.
