My Servers

Start, stop and look after every server.

Every server you create, on every computer, with its state, address and uptime. Open one for its console, files, backups and settings.

  • Console & commands: send a command or follow the live console.
  • Files: browse and edit server files without another tool.
  • Backups: whole-server or world-only backups you can restore later.
  • Logs & diagnostics: stream logs and collect redacted diagnostics.

Computers

Every machine, one control plane.

Pair a Windows PC, a gaming desktop or a headless Linux box. Each one becomes a computer whose servers, files and Node Health live in the same workspace.

  • Node Health: CPU, memory, disk and network for every computer.
  • AnxNet: a private network for your own computers and friends' devices.
  • Honest status: an offline computer says so, and its last list is marked as last known.

Live health appears after you connect an Agent.

First server workflow

From a bare machine to a running server.

Templates install onto the computer you paired. If a runtime is missing, Prepare Node installs Java, SteamCMD and other Runtime Dependencies with your approval before the first start.

  1. Add a computer

    Pair the machine that will run the server, or use this PC.

  2. Pick a template

    Minecraft Java editions and modpacks, SteamCMD titles and apps.

  3. Create

    Set the name, memory and port. AnxHost checks what the server needs.

  4. Run

    Watch the console, health and players; stop, update or back up when you need to.

Add Server

Search templates, choose the computer, and create. FiveM is experimental and needs a server license key that you provide.

  • Minecraft Java: Vanilla, Paper, Purpur, Fabric, Forge, NeoForge and Modrinth modpacks.
  • SteamCMD titles: Palworld, Valheim, Rust, CS2 and Terraria.
  • Apps: media servers, bots and your own Node.js, Python or Java project.

Add a computer

Adding a computer is the whole setup.

Two paths, one result: a paired computer. Desktop or headless, pairing takes a few minutes. Manual tokens are the Advanced recovery path, not the normal one.

Desktop computer

Windows or desktop Linux

Install AnxHost Control Center there, open Agent Control, select Connect this computer and Generate Pairing Code, then paste the code under Add Computer.

Headless server

Debian or Ubuntu

Install AnxOS-Agent-<version>.deb with sudo apt install, run anxos-agent pair and paste the one-time code under Add Computer.

Headless Linux

Headless Linux is first-class.

On Debian and Ubuntu the Agent ships as an official package and runs as a system service with a full-screen TUI.

  • Official AnxOS-Agent-<version>.deb for Debian 11+ and Ubuntu 22.04+ on x64.
  • Installs as anxos-agent.service, managed by your package manager.
  • Run anxos-agent for status, or anxos-agent pair for a one-time pairing code.
  • Linux builds are not code-signed: verify the published SHA-256 checksums.

Security posture

Trust is a feature.

The AnxHost Local Agent securely connects the desktop app to services running on your computer. These are the boundaries it keeps by default.

  • One-time pairing codes that expire; generate a fresh code for each computer.
  • Loopback by default: the Agent listens on 127.0.0.1 unless you opt in to network exposure.
  • Signed Windows installer; Linux packages publish SHA-256 checksums.
  • Uninstall keeps your data: servers, worlds and configuration stay in place.
  • Redacted diagnostics: fingerprints and timestamps, not secrets.
