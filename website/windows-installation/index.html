Install AnxOS and Prepare This PC

This guide follows the normal Windows 11 x64 setup flow. You should not need terminal commands, manual JSON edits, Node.js installation, or Agent token copying — the installer sets up the Local Agent for you.

Step by step

Set up this PC in eleven steps

From the installer to your first server, using the normal Windows flow. Windows may ask for administrator permission once, when the Local Agent service is installed.

1

Download the Windows installer

Open the download page and get the signed Windows setup from the official GitHub Release.

2

Open the installer

Run the downloaded file after the download finishes. The setup installs AnxOS Control Center and adds the normal Start menu and desktop shortcuts.

3

SmartScreen warning

The installer is code-signed, but Windows SmartScreen can still warn on a newer publisher. Verify the publisher name and that the file name matches the release page — choose More info → Run anyway only when both match. If they do not match, cancel and download again from the official release.

4

Launch AnxOS Control Center

Open AnxOS from the Start menu or the desktop shortcut.

5

Complete onboarding

Complete the first-run onboarding and choose Use This PC so the app treats this computer as your local node, then sign in or create your account.

6

Install the Local Agent

Open Agent Control and install the Local Agent from inside AnxOS. The app pairs with the bundled Agent automatically.

7

Allow administrator permission

Approve the Windows prompt that installs the Local Agent service. This is the only step that needs administrator access.

8

Let AnxOS scan dependencies

AnxOS scans for Java, Git, SteamCMD, Docker, FFmpeg, and tunnel providers, and reports what is missing.

9

Install required dependencies

Install the listed items through AnxOS when a Marketplace template needs them, then run the scan again.

10

Open Marketplace

Open Marketplace and choose a template, for example a Minecraft server or modpack.

11

Create your first server

Choose the node, memory, port, and install location, then start the installation. Manage it afterwards from Instances, Files, Backups, Console, and Public Access.

More computers

Adding another computer?

This page stays Windows-focused. The setup guide covers the other two paths — and both of them are one-time pairing-code flows, with no manual tokens or file editing.

Another desktop computerDesktop

Install Control Center on that computer, then open Agent Control → Connect this computer, turn on Another computer will connect to this one, and generate a pairing code. Paste the full code under Add Computer in your main Control Center.

 Headless Linux serverDebian / Ubuntu

Install the official Agent package on Debian 11+ or Ubuntu 22.04+ x64, open the TUI, and pair it with a one-time code. The setup guide has the exact commands with copy buttons.
Using Linux instead?

This page stays Windows-focused. The setup guide covers Linux desktop packages and the headless Debian or Ubuntu Agent, and the system requirements page lists both desktop platforms.

Troubleshooting

Common Windows setup issues

Known Windows-specific problems and their fixes. For Agent, dependency, and server problems shared with other platforms, see the setup guide.

Windows SmartScreen warning

The installer is code-signed, but SmartScreen can still warn on a newer publisher. Verify the publisher and that the file name matches the release page, then choose More info → Run anyway only when both match. If they do not match, cancel and download again.

Local Agent installation failure

Use Retry or Repair in AnxOS. If antivirus software quarantined files, restore the official installer or Agent files before retrying.

Administrator permission denied

Sign in to a Windows administrator account or ask the computer owner to approve the Local Agent service installation.

Agent offline

Open Agent diagnostics in AnxOS and restart or repair the Local Agent service. The desktop app keeps running while the service starts.

Port already in use

Close the other app using the port or choose a different server port before installing or starting the server.

Antivirus quarantine

Only restore files when they came from the official AnxOS release. Then run Local Agent repair so AnxOS can verify the installation.

Docker restart required

Finish the Docker Desktop setup or restart Windows when Docker asks, then scan dependencies again.

Windows restart required

Restart Windows when an installer or driver requests it, then open AnxOS and retry the setup step.
