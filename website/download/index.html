Before you install

System requirements

AnxOS itself needs modest resources; the servers and backups you run on top of it need their own space.

Windows desktop

Windows 11 x64 with administrator access during the Local Agent install. 4 GB RAM minimum, 8 GB or more recommended, and 2 GB free storage for the app and Agent.

Linux desktop

Debian 11+ or Ubuntu 22.04+ x64 with the same memory and storage guidance. Install packages with your distribution's package manager.

Headless server

Debian 11+ or Ubuntu 22.04+ x64 with glibc 2.28 or newer and systemd for the Agent service. The server must stay powered on and reachable when you manage it.

Servers, modpacks, and backups need additional disk space, and internet access is required for downloads, updates, and dependency installers.
