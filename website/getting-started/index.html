Desktop walkthrough

Run your first server on Windows

This is the desktop sequence in the current app. Every step happens inside AnxOS; no terminal commands are needed on Windows.

1
Download the Windows installer

Get the signed Windows 11 x64 installer from the download page. Linux users can take the .deb or .AppImage instead.

2
Open the installer

Run the setup. If SmartScreen shows its blue warning for a new publisher, choose More info, then Run anyway.

3
Launch AnxOS and complete onboarding

Creating an account is optional; local mode works offline on your own machine.

4
Install the Local Agent

Allow the administrator permission prompt once so AnxOS can install and start the managed Agent on this PC.

5
Add this PC as a node

The computer running Control Center is offered as a node, so you can start without pairing anything.

6
Run Prepare Node

AnxOS scans for Java, SteamCMD, Docker, and other runtimes the templates need and lists what is missing.

7
Install required dependencies

Approve the installs Prepare Node recommends, then open the Marketplace.

8
Create and start your first server

Pick a template and the target node, create the server, and start it. Instances shows it move from starting to running.

Adding a headless Debian or Ubuntu server instead?

Install the official AnxOS Agent .deb on Debian 11+ or Ubuntu 22.04+ x64. It runs as a systemd service with its own CLI/TUI and shows a one-time pairing code; paste that code into Pair with Code on this machine and the node appears in Nodes.

Before you start

What you'll need

  • Windows 11 x64, or Debian/Ubuntu x64Control Center runs on Windows 11 x64; Linux builds cover Debian/Ubuntu x64 as .deb or .AppImage. Headless servers use the Agent .deb on Debian 11+ or Ubuntu 22.04+ x64.
  • 4 GB RAM minimumFor the app and the Local Agent; game servers and backups need more.
  • Your machine stays onA server keeps running only while the computer hosting it is powered on.
  • Admin or sudo for one install stepWindows administrator permission for the Local Agent; sudo on Linux for the Agent package.
AnxOS does not provide hosting capacity

The machine is yours to provide: this PC, another desktop, or a headless server you own or rent. AnxOS manages what runs on it and does not sell hosting.
