## Which file do I need?

| You have… | Download |
| --- | --- |
| A Windows 11 x64 PC | `AnxOS-Control-Center-Setup-<version>.exe` (installs and updates itself), or the `-portable.exe` to run without installing |
| A Debian or Ubuntu x64 desktop | The `AnxOS-Control-Center-<version>.deb`, or the `.AppImage` for other distributions |
| A headless Debian 11+ / Ubuntu 22.04+ server | `AnxOS-Agent-<version>.deb`, then pair it from the Control Center app |

`latest.yml`, `latest-linux.yml` and `update-manifest.json` are read by the app's updater. You don't need to download them.

## Verify your download

Every release publishes a `SHA256SUMS` file covering every package, and the Agent package also has its own `.sha256` file.

**Windows (PowerShell):**

```powershell
Get-FileHash .\AnxOS-Control-Center-Setup-<version>.exe -Algorithm SHA256
Get-AuthenticodeSignature .\AnxOS-Control-Center-Setup-<version>.exe
```

The hash must match the line for that file in `SHA256SUMS`, and the signature status must be **Valid**. The Windows installer is Authenticode-signed with Azure Trusted Signing; you can also check the publisher under **Properties › Digital Signatures** before installing.

**Linux:**

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

The Linux `.deb`, the AppImage and the Agent `.deb` are not code-signed; check them against `SHA256SUMS`.

## Upgrading

- **Windows:** run the new Setup over your current installation, or accept the update the app offers. Your servers, settings, backups, paired computers and the AnxHost Helper are kept.
- **Linux desktop:** install the new `.deb` over the old one (`sudo apt install ./AnxOS-Control-Center-<version>.deb`), or replace the AppImage.
- **Headless Agent:** install the new `AnxOS-Agent-<version>.deb`. Updating or restarting an Agent stops every server it runs, so back up and stop them from the app first, then start them again afterwards.

## Release channels

New builds are published here as **pre-releases** first. A build becomes the **Latest** release only after it has been installed and accepted on real machines; the website and the app's updater then point to it. Every public build so far is **Private Alpha**.

## Security

- Windows installers are Authenticode-signed; the app's updater checks each download against the SHA-512 in the published updater metadata before installing it.
- Computers pair with one-time codes, and each paired Agent keeps its own credential.
- Server, mod and package downloads are checked against the checksums their publishers provide.

If you find a security problem, don't post the details in a public issue: open an issue asking for a private contact, and leave out anything that would let someone else reproduce it.

## Known limitations

See [Known Limitations](https://github.com/AnxLabs/AnxOS-Control-Center/blob/main/docs/KNOWN_LIMITATIONS.md). In short: Private Alpha builds change quickly, Linux packages are checksum-verified but not code-signed, Windows SmartScreen may warn about a new download until it builds reputation, and updating an Agent stops the servers it runs.

## Report a problem

Open an issue in the [main repository](https://github.com/AnxLabs/AnxOS-Control-Center/issues) with the build number, what you did, what happened, and a screenshot or the app's exported diagnostics. Never include passwords, Agent tokens, pairing codes or unredacted logs.
